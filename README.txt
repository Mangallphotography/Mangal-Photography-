MANGALL PHOTOGRAPHY — PORTFOLIO WEBSITE
==========================================

1. Open index.html locally to preview.
2. Replace the 9 demo JPG files in assets/ with your own photographs:
   hero.jpg, about.jpg, photo1.jpg ... photo7.jpg
3. Keep the filenames the same, or edit the CSS in index.html.
4. Update package pricing/inclusions in the Packages section.
5. The contact form opens WhatsApp to +91 74772 96125.
6. Instagram: @mangall_photography
7. Location: Karju, Shajapur, Madhya Pradesh

VERCEL:
- Upload this folder to a GitHub repository.
- On Vercel, choose "Add New Project" and import the repository.
- Framework preset: Other / None.
- Build command: leave empty.
- Output directory: .
- Deploy.

The site is plain HTML/CSS/JS, so it needs no build step.
